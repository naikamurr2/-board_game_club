# BoardGameClub



Приложение для учёта клиентов, настольных игр и проката игр в клубе «Мипл».



## Автор



Могильный Ярослав, группа РПО 1/24



## О проекте



**Тема:** прокат настольных игр.



**Заведение:** клуб настольных игр «Мипл».



«Мипл» — небольшой клуб в центре города, где можно взять напрокат настольную игру на вечер или на несколько суток. Приложением пользуется администратор клуба: он ведёт каталог игр, регистрирует клиентов и записывает каждую выдачу и возврат. Клиенты клуба — компании друзей, семьи и студенты, которым нужна игра на выходные. Главное отличие «Мипла» от обычных магазинов и прокатов в том, что у каждой игры указаны сложность от 1 до 5 и количество игроков. Поэтому администратор за минуту подбирает игру под конкретную компанию, а постоянные клиенты с клубной картой получают скидку.

## Таблицы

### Clients

В таблице хранятся клиенты клуба, которые берут игры напрокат.

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| Id | int | да | Первичный ключ |
| FullName | string | да | Фамилия и имя клиента |
| Phone | string | нет | Телефон для связи |
| RegistrationDate | DateTime | да | Дата регистрации в клубе |
| HasClubCard | bool | да | Есть ли у клиента клубная карта со скидкой |

### Games

В таблице хранятся настольные игры из каталога клуба.

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| Id | int | да | Первичный ключ |
| Title | string | да | Название игры |
| MinPlayers | int | да | Минимальное число игроков |
| MaxPlayers | int | да | Максимальное число игроков |
| Complexity | int | да | Сложность игры от 1 до 5 |
| PricePerDay | int | да | Стоимость проката за сутки, руб. |
| Description | string | нет | Короткое описание игры |

### Rentals

В таблице записано, какой клиент какую игру и когда взял напрокат.

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| Id | int | да | Первичный ключ |
| ClientId | int | да | Внешний ключ на таблицу Clients |
| GameId | int | да | Внешний ключ на таблицу Games |
| StartDate | DateTime | да | Дата и время выдачи игры |
| ReturnDate | DateTime | нет | Дата и время возврата, пусто, пока игра у клиента |
| TotalPrice | int | да | Итоговая стоимость проката, руб. |

## Связи

- **Clients → Rentals** (один ко многим): связь идёт через внешний ключ `Rentals.ClientId`. Один клиент может взять игры напрокат много раз.
- **Games → Rentals** (один ко многим): связь идёт через внешний ключ `Rentals.GameId`. Одну и ту же игру могут брать много раз.

В итоге таблицы `Clients` и `Games` связаны «многие ко многим» через связующую таблицу `Rentals`. Один клиент берёт много разных игр, а одну игру берут многие клиенты. Каждая строка в `Rentals` фиксирует одну выдачу: конкретного клиента, конкретную игру, дату выдачи, дату возврата и стоимость.
